# 針の穴チャレンジ（試作版）

スマホ向けの「針の穴に糸を通す」ワンタップゲームの試作です。`index.html` 1ファイルで動きます。

## 遊び方
- 糸が左右に動いています。穴の真下に来たら画面をタップ。
- 穴に近づくとスローになり、カメラが寄ります。
- 成功 5〜25 / 失敗 2 コイン。初クリア 11〜110、相性の良い針と糸なら +10。
- 初期装備以下の組み合わせで、道具を使わずにクリアすると王冠（素手クリア）。

## ステージ構成（全100・10章）
1 ちゃぶ台 / 2 公園のブランコ（針がゆれる） / 3 扇風機の前（風） / 4 満員電車（一定リズムでガタン） / 5 雪の朝（手が震える）
6 船の上（全部ゆれる） / 7 夜なべ（電灯が暗くなる） / 8 ねこのいる部屋（ねこパンチ） / 9 宇宙ステーション（無重力） / 10 はるか彼方（総まとめ）
