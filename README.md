# 針の穴チャレンジ（試作版）

スマホ向けの「針の穴に糸を通す」ワンタップゲームの試作です。`index.html` 1ファイルで動きます。

## 遊び方
- 糸が左右に動いています。穴の真下に来たら画面をタップ。
- 穴に近づくとスローになり、カメラが寄ります。
- 成功 +30 / 失敗 +5 コイン。初クリア +50、相性の良い針と糸なら +20。
- 初期装備以下の組み合わせで、道具を使わずにクリアすると王冠（素手クリア）。

## ステージ構成（全30）
1-5 ちゃぶ台 / 6-10 ゆれる針 / 11-15 扇風機の前（風） / 16-20 満員電車（ガタン揺れ） / 21-25 手がふるえる / 26-29 船の上 / 30 はるか彼方
